### 工作内容

按开发计划步骤 1 分给前端的清单执行：

- 初始化 Vite + Vue 3 工程（**JavaScript 而非 TypeScript**，依据项目结构文档第 3 节全部标注 `.js`）；
- `vite.config.js`：端口 5173（与后端 CORS 白名单一致），`/api` 代理至 `http://localhost:8000`，**不做 rewrite**（后端路径本身即 `/api/v1/*`）；
- 路由表 9 条：8 个菜单页 + 1 个隐藏页（`/interview/:sessionId`，不进菜单）；
- 布局三件套：`App.vue`（容器骨架 + 折叠状态）、`components/SideNav.vue`（菜单渲染 + 路由高亮）、`components/AppHeader.vue`（折叠按钮 + 页面标题 + `actions` 插槽）；
- `src/api/request.js`：axios 实例（`baseURL = /api/v1`）+ 统一响应体拦截——成功分支解包 `response.data.data`（调用方直接拿业务数据），失败分支按「超时 / 有响应体 / 无响应」三类提示并透传业务错误码；
- 9 个占位页 `src/views/*.vue`，统一 `el-empty` 占位并标注对应开发步骤；
- `main.js` 挂载顺序：Pinia → Router → Element Plus（全量引入 + `zh-cn` locale）。

### 决策与遗留

| 决策 | 理由 |
|---|---|
| 不建 `src/stores/` 目录 | 本步无任何真实 store 需求（设置项→步骤 7、概览轮询→步骤 5、悬浮球→步骤 16）；`main.js` 照常挂载 Pinia 为后续铺路 |
| 不建业务接口文件（`api/applications.js` 等） | 随各业务步骤交付，避免创建空文件 |
| 引入 `@element-plus/icons-vue` | 项目结构文档依赖清单未列此包，但**折叠侧边栏**是本步既定形态——折叠后菜单只剩图标位，无图标则侧边栏成为空白窄条。按需引入，不做全局注册 |
| 不建 `public/` 目录 | `index.html` 的 favicon 用内联 SVG data URI，避免新增文档外目录 |
| 概览页保留后端连接状态卡片 | 步骤 1 验收要求「`/health` 通」，这是验证 `request.js` 全链路（axios → baseURL → Vite 代理 → 拦截器 → 后端响应体）的唯一手段；步骤 5 实现真正概览页时在此基础上扩展，非废弃代码 |

**遗留**：`tests/conftest.py` 的完整版（独立测试库 + `FakeLLMProvider`）依赖步骤 2 / 6 的模块，本步无法完成——该欠账在[测试日志](测试日志.md)中跟踪。

## 视觉改版（系统设计文档 4.4 / 4.5 对齐）

| 项 | 内容 |
|---|---|
| 完成日期 | 2026-09-24 |
| 性质 | **非开发计划步骤**，属系统设计文档 v1.2 新增章节（4.4 全局布局 / 4.5 视觉设计系统）的代码同步 |
| 对应分支 | `frontend` |

### 工作内容

- **新增 `src/styles/tokens.css`**：色彩 / 间距 / 圆角 / 布局尺寸全部收敛为 CSS 变量，并在其上覆盖 Element Plus 主题变量（**只改视觉变量，不改组件行为**）。派生色按 Element Plus 的 `mix(white, 主色, n/10)` 算法计算，保证与其内部组件配色自洽；
- **品牌与模块色定稿**：主色品牌紫 `#6B4E9E`；8 个模块各有模块色；投递 5 个状态色对齐数据库设计文档第 5 章枚举；
- **路由表 `meta` 扩展**：新增 `group`（菜单分组，侧栏按此分组）与 `color`（模块色），移除 8 个 Element Plus 图标的 import（菜单改用模块色点）；
- **`request.js` 增加 `silent` 选项**：辅助性请求失败时不自动弹提示，由调用方降级；
- **`SideNav.vue` 重写**：品牌区 + 三组菜单（求职流程 / 能力提升 / 系统）+ 模块色点 + 底部「今日待办」；折叠态下组标题收为细分隔线；
- **`AppHeader.vue`**：折叠按钮 + 当前页标题 + `actions` 具名插槽 + 提醒入口 + 「＋ 新增投递」高频操作；
- **`App.vue`**：侧栏宽度 210px → **230px**（设计文档 4.4 新规格），内容区 padding 统一走 token；
- **9 个页面去掉与顶栏重复的 `<h2>`**（顶栏已渲染 `meta.title`，页内再渲染一次即同屏两个相同标题）。
