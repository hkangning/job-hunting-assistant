## 1. 测试策略

### 1.1 总原则

- **LLM 调用 100% mock**：测试离线可跑、不产生 API 调用费用、结果确定（SRS NFR-012）。真实供应商联调用**一次手动冒烟**验证（见 5.1），不入自动化；
- 测试金字塔：服务层单元测试 > API 集成测试 > 前端手工验收；SSE 流式链路有专项集成测试；
- 测试数据库用**独立的 MySQL 库**（`job_hunter_test`），不碰开发库 `job_hunter`。连接串由 `conftest.py` 在模块级从 `backend/.env` 的 `DATABASE_URL` **派生**（只换库名、凭据沿用，不写死密码），必须排在**任何 `app.*` 导入之前**——`app/config.py` 的 `Settings` 在模块导入时即读取环境变量。逐例隔离用 **TRUNCATE**（MySQL 的 DDL 是重量级操作，当前 22 张表 × 全部用例不再逐例 DROP+CREATE）；`question` 表种子会话内只导一次、不参与清空。

| 项 | 选型 |
|---|---|
| 测试框架 | pytest + pytest-asyncio |
| API 测试 | FastAPI TestClient（依赖注入替换 LLM） |
| Mock | `FakeLLMClient` / `FakeASR` / `FakeTts`（见下）；测试期不启用定时调度器 |

### 1.3 LLM Mock 方案

`app/clients/llm_client.py`（**步骤 10**）定义抽象 **`LLMClient`**，生产实现为 **`OpenAICompatibleClient`**（12 家供应商同走 OpenAI 兼容协议）。测试 `conftest.py` 注入 **`FakeLLMClient`**（**步骤 10 交付**）：

> **模块归属**：`llm_provider.py` 是**步骤 6** 交付的模块——12 家供应商注册表 + `test_connection` / `list_models` 探测函数，**不含抽象基类**；抽象 `LLMClient` 与可替换的客户端实例属**步骤 10** 的 `llm_client.py`。

- `stream_chat()` 返回**预设 token 序列**（按场景预置：JD 五段报告、面试点评+下一题、八股点评等），可断言落库内容；
- `chat_json()` 返回预设 dict（面经条目/错题判定）；
- `list_models()` 返回预设模型列表（或 `fail=True` 模拟拉取失败，验证回退内置表路径，见 TC-49）——**注**：该函数与 `test_connection()` 同是**步骤 6 `llm_provider.py` 的模块级函数**（非抽象基类的方法），mock 以 monkeypatch 该函数实现；
- 可配置 `error` 模拟 LLM 异常，验证兜底路径（错误码 10010/10011）；
- 可配置 `delay=0.001` 模拟流式节奏，验证 SSE 事件顺序。

**注入方式**：`app.dependency_overrides[get_llm_client]`（**步骤 10** 交付的注入点；**每请求新建实例**，非单例——不做成单例，避免并发请求共享同一实例的状态）——替身实现 `stream_chat` / `chat_json` 两个方法即可，生产代码零改动。

### 5.1 真实供应商冒烟（默认 DeepSeek，配置 .env 或设置页后）

### 5.2 语音链路冒烟（P2 开发后）

1. **ASR**：启动后端（FunASR 本地模型首次需联网下载约 0.9GB，此后离线可用）→ 连续说话 1 分钟以上、其间多次停顿 → 确认静音自动断句、逐句转写文本正确且每句 **<1.5s**（NFR-002，本地模型热推理实测**约 8 倍实时、数秒级短句约 0.2~0.8 秒**、14 秒音频约 1.7 秒）；
2. **断网复测**：断开外网重跑第 1 步，确认识别仍可用（本地模型不出网）；
3. **TTS**：`POST /tts/synthesize` 合成一段文本 → 返回 mp3 可播放；设置页切换音色后重新合成，**音色即时变化**；同一文本二次合成**命中 sha1 缓存**（响应明显更快、不重复调 edge-tts；命中为纯本地读文件，断网亦可复播）。

> **本轮实测**（2026-10-06，前端步骤 24 落地）：后端 B 套已实证缓存命中 0.034s 与断网复播（后端工作日志步骤 24 节）；前端 CDP 走查 **26/26**（假麦克风样本 → VAD 切句 → 真 FunASR 转写回填 → 提交携带 `segments` → edge-tts 播报与打断），见[前端工作日志](../07-工作日志/前端工作日志.md)步骤 24 节。
