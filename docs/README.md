# 文档目录

本目录存放项目全部文档，是开发的**唯一依据来源**。

## 工作约定（必须遵守）

1. **文档先行**：任何开发工作开始前，先在本文档目录下完成对应文档并确认定稿。
2. **严格按文档执行**：开发过程中严格按照本文档目录下的文档编写代码，严禁自由发挥、严禁实现文档中未约定的功能。
3. **文档变更流程**：需求或设计发生变化时，先修改文档，再改代码。
4. **代码与文档一致性**：文档更新后，检查相关代码和其余文档是否需要同步更新。

```
需求规格说明书 ──→ 系统设计文档 ──→ 项目结构
```

修改任一文档后，按下游方向检查其余文档口径是否需同步（如改状态枚举：需求 4.1 → 数据库第 5 章 → 接口错误码/参数说明 → 测试用例）。

**关于 `07-工作日志/`**：该目录存放开发与测试的**过程记录**，性质与 00~06 的「开发依据文档」不同——它**不参与上方依赖链**、不作为开发依据，只记录实际执行内容（命令、结果、决策理由），供阶段验收与复盘查阅。维护约定见各日志文首。
