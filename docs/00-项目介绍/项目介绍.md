## 1. 项目概述

个人求职助手是面向大四学生的求职全流程 AI 助手，覆盖"**投递管理 → JD 匹配分析 → 笔试备战 → AI 模拟面试 → 面经复盘**"一条完整链路。

产品形态为**工作台**（结构化页面 + 数据看板），而非聊天框套壳大模型：AI 能力嵌入每个具体操作流（一句话录入投递、流式 JD 分析报告、逐题面试点评），同时提供全局 Agent 悬浮球作为跨页面快捷入口，支持自然语言驱动真实操作（如"记一笔投递"）。

系统为**多账号**形态：注册登录后使用，投递、面经、错题、AI 供应商配置等数据按账号隔离，各账号互不可见，为后续高级功能预留账号底座。

## 2. 选题背景

大四求职季存在五个典型痛点，本项目一一对应：

| 痛点 | 对应功能 |
|---|---|
| 投递记录散落在表格与聊天记录中，容易漏跟进 | 投递管理看板 + 3 天无进展自动提醒 |
| JD 冗长难读，无法快速判断匹配度 | JD 匹配分析（评分 + 差距 + 准备建议） |
| 笔试八股复习没有反馈，答错即忘 | 八股陪练 + 错题本（艾宾浩斯复习档位） |
| 模拟面试缺乏客观点评 | AI 模拟面试（逐题评分 + 总结报告 + 语音作答） |
| 面经看完即忘，无法沉淀复用 | 面经结构化存储与检索 |

选题贴近真实需求，功能链路完整，适合作为软件工程课程的综合实践项目。

## 3. 项目目标

1. **功能完整**：五大功能线全部可演示，形成闭环；
2. **低延迟**：AI 输出全部流式渲染，首字延迟 < 2s，交互流畅；
3. **工程规范**：文档先行（需求/设计/数据库/接口/测试/开发计划六类文档）、分层架构、异常兜底完善、测试覆盖核心链路。

## 4. 技术栈与选型理由

| 层 | 技术 | 选型理由 |
|---|---|---|
| 后端语言 | Python 3.11+ | 课程技术栈要求（C++/Python 二选一）；生态适合快速开发 |
| 后端框架 | FastAPI | 原生异步、SSE 流式支持好、自带 OpenAPI 文档、Pydantic 校验 |
| 数据库 | MySQL 8.0（InnoDB，utf8mb4）+ SQLAlchemy 2.x | 具备完整事务与并发写能力，题库（**585 题**，5 个技术栈 / 18 个领域 / 含 152 道场景题）、多账号数据与采集任务同库承载；ORM 参数化防注入、便于迁移 |
| AI 接入 | 多供应商+模型级可配置（**12 家**：国内 DeepSeek / 智谱 / Kimi / 通义千问 / 豆包，国外 OpenAI / Gemini / Claude / Grok，聚合 OpenRouter，本地 Ollama，自定义） | 全部基于 OpenAI 兼容协议，一套 SDK 切换多家；模型列表动态拉取保持最新；**每账号独立配置、多供应商并存可一键切换**（Key 由账号自备，平台不经手、不代付）；Ollama 本地模型可作断网兜底 |
| Agent | 手写实现（意图路由 + 工具注册 + 画像记忆） | 体现智能体设计能力，逻辑透明可控，避免框架黑盒与额外依赖 |
| 语音 | 转写：**FunASR 本地流式模型**（默认，进程内运行、不限时长、零费用、不出网）；播报：**edge-tts**（免费、中文音色 20+） | 讯飞「语音听写」单次 ≤60 秒，做不了长时长作答；浏览器 `speechSynthesis` 中文音色塑料感重。FunASR 本地 + edge-tts 兼顾**长时长**与**音色鲜活**，且断网可演示；讯飞云端作可选备选 |
| 前端 | Vue 3 + Vite + Element Plus + Pinia | 生态成熟、组件齐全；前后端分离便于两人并行开发 |
| 定时任务 | APScheduler | 轻量、进程内运行，满足每日检查类任务 |
| 测试 | pytest + FastAPI TestClient | LLM 调用全部 mock，测试离线可跑、结果确定、不产生调用费用 |

## 5. 团队分工

| 成员 | 职责 |
|---|---|
| 胡康宁 | 后端开发、数据库设计、AI 供应商接入 |
| 卢世君 | 前端开发、测试用例编写与执行、测试计划文档维护 |

**协作方式**：

- 以接口文档为前后端协作契约：后端按接口文档先行实现并自测，前端按接口文档并行开发；
- 文档先行：需求/设计变更先改文档，再动代码；
- 测试随开发：每步代码完成后按测试计划执行对应用例，通过后才验收；
- git 协作：功能分支开发，主干合并前跑通测试。

## 6. 功能概览

| 模块 | 核心能力 |
|---|---|
| 今日概览 | 待面试置顶、投递统计、跟进提醒、错题到期提醒、就业网宣讲会 |
| 投递管理 | 看板式维护、状态流转、三方式录入（表单/Agent 一句话/批量导入） |
| JD 匹配分析 | 粘贴 JD → 流式输出五段报告（评分/分项/优势/差距/建议） |
| AI 模拟面试 | 携带公司岗位上下文逐题问答、每题点评打分、总结报告、语音作答 |
| 面经整理 | 粘贴原文 → AI 结构化提取 → 关键词检索 |
| 笔试备战 | 八股陪练（答题→点评→自动入错题本）+ 错题本（档位复习 + AI 抽问） |
| 全局 Agent | 悬浮球任意页面唤起，意图路由 + 工具调用 + 画像记忆 |
